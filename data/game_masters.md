# WORD SIEGE — ゲームマスタ・難易度仕様

このファイルは **敵の強さの伸び方** と **ウェーブ報酬（強化カード）** の一覧を、実装と同じ前提でまとめたマスタです。バランス調整時は `client/src/game/` の式と併せて更新してください。

---

## 1. 用語

| 用語 | 意味 |
|------|------|
| **waveGlobal** | 通算で何ウェーブ目か（1 起算）。`beginAnnounce` のたびに +1。リザルトの到達ウェーブ等。 |
| **Weff**（難易度に使う W） | 敵の強さ・数・弾速などの式に入れる整数。モードで定義が異なる（下記）。 |
| **STAGE** | ストーリーのみ。各 STAGE で WAVE 1〜10。 |
| **waveInStage** | 現在 STAGE 内の WAVE（1〜10）。 |

### 難易度 Weff の定義（実装: `GameEngine.difficultyW()`）

- **エンドレス**: `Weff = waveGlobal`（従来どおり通算のみ）。
- **ストーリー**: `Weff = waveInStage + (stage - 1) × STORY_STAGE_DIFFICULTY_OFFSET`  
  - `STORY_STAGE_DIFFICULTY_OFFSET` は `playfield.ts`（既定 **8**）。  
  - 例: STAGE 1 の WAVE 1 → Weff=1。STAGE 2 の WAVE 1 → Weff=1+8=9（STAGE 1 の終盤に近い強さから開始）。  
  - **同じ WAVE 番号でもステージが進むほど敵が強く・多い**。

### ボス出現ウェーブ

- **ストーリー**: `waveInStage > 0` かつ `waveInStage % 5 === 0`（各 STAGE の WAVE 5・10）。
- **エンドレス**: `waveGlobal > 0` かつ `waveGlobal % 5 === 0`。

## 2. Weff で変わるパラメータ

以下の **W はすべて Weff**（上表）。実装: `engine.ts` / `monster.ts`。

| パラメータ | 計算式（概要） | 上限など |
|------------|----------------|----------|
| 最大同時出現数 | `min(8, ceil(W/5) + 1)` | 8 |
| 敵の移動速度 | `min(200, 40 + W*3)` px/s | 200 |
| **通常敵 HP** | `min(5, 1 + floor(W/8))` | 5 |
| **精鋭 HP** | `max(3, 通常HP × 3)` | — |
| **ボス HP** | `min(20, 5 + W)` | 20 |
| スポーン間隔 | `max(0.8, 3.0 - W*0.05)` 秒 | 0.8 秒 |
| ウェーブ出現数 | `min(40, 6 + W*2)` | 40 |
| 精鋭出現率（非レア時） | `min(0.25, 0.05 + W*0.005)` | 25% |
| レア敵 | 非ボスで 12%（`monster.ts` の定数） | — |
| **敵弾速** | `min(420, 260 + W*5)` | 420 |
| **敵弾の発射間隔（秒）** | `w = max(0.5, 1 - W×0.012)` とし、**ボス** `max(0.32, 0.5×w)` ・**精鋭** `max(0.55, 1.05×w)` ・**通常/レア** `max(0.95, 2.15×w)`（通常 ＜ 精鋭 ＜ ボスの速さ） | `monster.ts` `enemyFireIntervalSec` |

### ストーリーとエンドレスの違い（要約）

- **ストーリー**: UI は STAGE / WAVE。難易度は **Weff（ステージオフセット付き）**、ボスは **STAGE 内の WAVE 5・10**。
- **エンドレス**: 難易度は **waveGlobal のみ**、ボスは **waveGlobal が 5 の倍数**のウェーブ。

## 3. ウェーブ報酬（強化カード）マスタ

実装: `client/src/game/upgrades.ts` の `UPGRADE_DEFS` / `pickUpgradeChoices`

ウェーブクリア後 **3 択**から 1 枚選択。スタック上限に達したカードは抽選から除外。  
（ダブルショット取得後のみトリプルショットが出現、などの排他ルールあり。）

| ID（API・内部名） | 表示名 | 効果（要約） | 最大スタック |
|-------------------|--------|--------------|--------------|
| `speed_aim` | スピードアップ | 自機移動速度 +20% | 5 |
| `rapid_fire` | ラピッドファイア | 発射クールダウン -0.04s（最小 0.10s） | 5 |
| `double_shot` | ダブルショット | 2 発同時（縦ずらし） | 1 |
| `triple_shot` | トリプルショット | 3 発扇状（ダブル後にのみ出現） | 1 |
| `pierce` | 貫通弾 | 最大 3 体まで貫通 | 2 |
| `pierce_burst` | ピアスバースト | 撃破時に拡散弾 | 2 |
| `fortress_shield` | ライフ回復 | 自機 HP +1（最大まで） | 実質無制限 |
| `sniper` | スナイパーモード | 自弾速度 +50% | 3 |
| `magnet` | マグネット | 自弾が弱ホーミング | 2 |
| `score_boost` | スコアブースト | キルスコア +20% | 5 |

抽選で 3 枚が足りない場合のフォールバック: `fortress_shield` で埋める（実装依存）。

## 4. スコア・コンボ（撃破時）

実装: `client/src/game/scoring.ts` / `engine.ts`

- 基底: `100 + 最大HP × 30`
- コンボ倍率: `1 + min(5, コンボ) × 0.12`（**その撃破の直前**のコンボ数）
- ボス ×3、精鋭 ×2、レア ×2.25、スコアブーストを乗算
- 小数切り捨て

### コンボのリセット

- **敵弾に当たってダメージを受けたとき、コンボは 0 にリセット**（`engine.ts` `processEnemyBullets`）。

## 5. 固定プレイフィールド

- 論理サイズ: **`playfield.ts`** の `PLAYFIELD_WIDTH` × `PLAYFIELD_HEIGHT`（現在 960×540）。
- ステージ難易オフセット: 同ファイルの `STORY_STAGE_DIFFICULTY_OFFSET`（現在 8）。
- UI はこのサイズに合わせ、`index.html` でレイアウト幅を揃える。
